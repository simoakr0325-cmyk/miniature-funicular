# 縄張り台（仮称）

山波創苑の外構・造園CAD。ブラウザだけで動き、電波のない現場でも開けます（PC が主、iPhone が従）。
2D の図が唯一の正本で、数量はそこから出します。一現場は一つの Obsidian ノートとして受け渡します。

## 動かす

```bash
npm start
```

`http://localhost:8080/` を開きます。外部ライブラリもビルドも要りません（Node.js 18 以上）。
iPhone で使うには、`app/` を HTTPS の置き場（Cloudflare Pages など）に置き、Safari で開いて「ホーム画面に追加」します。

## 試験

```bash
npm test
```

## 図面と印刷

- 図面は何枚でも持てます（全体の平面図と、門まわりなどの部分詳細図）。「図面」の欄の「足す」で、今見ている所を中心に細かい縮尺の一枚を足します。枠の中を押すとその図面に切り替わります。「全部を一つの PDF に」で一枚一頁の PDF にまとめます。
- PDF は線のまま（ベクタ）で、紙の上の寸法は縮尺どおりです。印刷するときは倍率を「実際のサイズ（100%）」にしてください。
- 日本語の書体は埋め込まず、標準の日本語書体名（平成角ゴシック）を指定しています。見る側の端末の日本語書体で表示されます。ファイルは小さく済みます。

## 平面直角座標

- 道具の「座標」から、地積測量図の座標一覧（一行に「点名 X Y」、単位 m、X が北・Y が東）を貼り付けると、敷地境界・線・点名を作ります。作る前に座標求積の面積と辺の長さを出すので、測量図の地積と見比べられます。
- 最初に入れた点の近くを図の原点として覚えます（`settings.geo`）。以後、選んだ部材の頂点座標が右の欄に出て（コピーもできる）、カーソルの位置の座標が右上に出ます。
- DXF は「測量座標で書き出す」を入れると、東が x・北が y の mm で書き出します。

## Obsidian のノートに添える図の絵

- Obsidian へ書き出す（フォルダに揃える・ノートを書き出す）たびに、図面と同じ描き方の絵（SVG）をノートに添えます。Obsidian の中で図を見られます。

## 下図の画像の掃除

- 外した下図の画像は、元に戻せるように端末とフォルダに残ります。上の現場の欄の「使っていない下図の画像を掃除」で、どの現場の図からも使われていない画像を端末から消します（いま開いている図の元に戻す履歴に残っているものは消しません）。
- Obsidian のフォルダの分は、Obsidian の欄の「フォルダの使っていない下図の画像を掃除」で消します。フォルダの中のどの縄張りノートからも使われていない「下図_…」の画像だけが対象です。

## DXF を下図に敷く

- 道具の「下図」で DXF（建築士の図など）を選ぶと、線のまま下図に敷きます。拡大しても滲みません。単位（$INSUNITS）を読んで実寸で敷き、図に測量座標の原点があって DXF がその近く（1 km 以内）なら、測量座標の位置に重ねます。
- 作図のときは、DXF の線の端・頂点・円の中心に吸い付きます。なぞって部材にできます。
- 読むもの：線・ポリライン（ふくらみも）・円・弧・楕円・スプライン（おおまか）・塗りつぶしの外形・文字・ブロック（扉など）・寸法。非表示の画層は読みません。文字の DXF（R12〜2018）を読み、2007 より前は Shift_JIS、以後は UTF-8 とみなします。バイナリ DXF と DWG は読めません。
- 元の DXF は `下図_〈指紋〉.dxf` として端末に置き、Obsidian へもそのまま渡します。PDF の図面にも線のまま入ります。

## DXF

- 「図面」の欄の「DXF を書き出す」から。AutoCAD R12 形式・Shift_JIS・mm 単位で、Jw_cad・AutoCAD・Vectorworks で開ける形を狙っています。
- 部材の種類ごとに画層を分けます（敷地境界・建物・舗装・植栽帯・景石・塀・擁壁・縁石・見切・樹木・高さ・寸法・文字・注記）。円弧の辺はふくらみ（bulge）のまま渡します。
- 塗り（ハッチング）と下図は入りません。寸法は線と文字で描きます（寸法の部品ではありません）。

## 中身

- `app/` アプリ本体（静的ファイルのみ）
  - `src/model.js` 図のデータの形、合わせ（同期）、数量
  - `src/obsidian.js` ノートへの書き出しと読み込み
  - `src/vault.js` vault のフォルダへの直接書き込み、共有シート
  - `src/underlay.js` 下図（PDF・写真の読み込み、縮尺・二点での合わせ）
  - `src/sheet.js` `src/plot.js` `src/pdfwriter.js` 図面（用紙・縮尺・表題欄）と PDF の組み立て
  - `src/dxf.js` `src/sjis.js` DXF の書き出しと Shift_JIS への変換
  - `src/survey.js` 平面直角座標（座標一覧の読み取り・座標求積・図との行き来）
  - `src/geometry.js` `src/hit.js` `src/render.js` `src/main.js` 計算・当たり判定・描画・操作
- `app/vendor/pdfjs/` PDF を読むための pdf.js 4.10.38（Apache 2.0、電波なしで使うため同梱）
- `tests/` 試験（`node --test`）
- `docs/` 確認事項・機能台帳・受け渡しの説明
