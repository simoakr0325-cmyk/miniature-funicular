# 縄張り台（仮称）

山波創苑の外構・造園CAD。ブラウザだけで動き、電波のない現場でも開けます（PC が主、iPhone が従）。
2D の図が唯一の正本で、数量はそこから出します。一現場は一つの Obsidian ノートとして受け渡します。

## 動かす

```bash
npm start
```

`http://localhost:8080/` を開きます。外部ライブラリもビルドも要りません（Node.js 18 以上）。
iPhone で使うには、`app/` を HTTPS の置き場（Cloudflare Pages など）に置き、Safari で開いて「ホーム画面に追加」します。

## 試験

```bash
npm test
```

## 図面と印刷

- 「図面」の欄の「描き方」で、**施工図**（表題欄）と **提案**（施主に見せる外構プラン）を選べます。提案は、平面図に材料ごとの色を付け、下に「〇〇様　外構プラン」の明朝の題と会社名・日付の帯を入れ、方位記号の下に「平面プラン　1/n」を添えます。題の名前は現場名から（「春日邸」→「春日様」）、「図名」を変えると「外構プラン」の所が変わります。
- 「植栽仕様表を載せる」を入れると、樹木を樹種と大きさ（H・C・W）ごとにまとめて記号の番号を振り、平面図の樹木に番号を、左下に植栽仕様表（記号・樹木名・H・C・W・数量・備考）を載せます。C は植木ノートの規格C です。
- 色は山波の三色（新緑 #5A9F4D・紅葉 #E68823・樹皮 #6B4C33）。新緑と紅葉をアクセントに使っています（画面の上の帯の線、見出し、提案の題の帯、植栽仕様表の見出し）。

- 図面は何枚でも持てます（全体の平面図と、門まわりなどの部分詳細図）。「図面」の欄の「足す」で、今見ている所を中心に細かい縮尺の一枚を足します。枠の中を押すとその図面に切り替わります。「全部を一つの PDF に」で一枚一頁の PDF にまとめます。
- PDF は線のまま（ベクタ）で、紙の上の寸法は縮尺どおりです。印刷するときは倍率を「実際のサイズ（100%）」にしてください。
- 日本語の書体は埋め込まず、標準の日本語書体名（平成角ゴシック）を指定しています。見る側の端末の日本語書体で表示されます。ファイルは小さく済みます。

## 平面直角座標

- 道具の「座標」から、地積測量図の座標一覧（一行に「点名 X Y」、単位 m、X が北・Y が東）を貼り付けると、敷地境界・線・点名を作ります。作る前に座標求積の面積と辺の長さを出すので、測量図の地積と見比べられます。
- 最初に入れた点の近くを図の原点として覚えます（`settings.geo`）。以後、選んだ部材の頂点座標が右の欄に出て（コピーもできる）、カーソルの位置の座標が右上に出ます。
- DXF は「測量座標で書き出す」を入れると、東が x・北が y の mm で書き出します。

## vault に置くノート

リポジトリの `vault/` は、Obsidian の vault にそのまま重ねる形にしてあります（`vault/10_辞書/植木/` に植木ノート 83 件と `植木の一覧.md`、`vault/10_辞書/工種/` に工種ノート 4 件）。`node tools/zip-vault.mjs vault.zip` で一つの ZIP にでき、展開した `10_辞書` フォルダを vault の `10_辞書` に重ねます。

## 樹種ライブラリ

- 正本は Obsidian の vault の `10_辞書/植木` のノートです（frontmatter に `分類: 植木`）。まだ無ければ、右の欄の「樹種ライブラリ」→「植木ノートを作る」で内蔵の 83 種をノートにします（PC はフォルダを選んで直接、iPhone は ZIP で）。リポジトリの [vault/10_辞書/](vault/10_辞書/) にも同じものを置いてあるので、そのまま vault にコピーしても構いません。既にあるノートは書き換えません。
- frontmatter に入れたのは図鑑で確かめられることだけです（和名・読み・学名・科〈APG〉・常落・葉形）。区分（高木・中木・低木・地被）は造園での使い方の目安です。規格（`規格H`・`規格W`・`規格C`、m）と `単価` は空にしてあるので、山波創苑の仕入れの決まりで埋めてください。耐寒性などの地域の数値は、根拠の資料（確認事項 11）が決まるまで入れません。
- 「vault の植木ノートを読む」で読み込むと、樹木の「樹種」の欄で候補が出て、選ぶと規格の H・W が樹高・葉張に入ります。vault のノートは内蔵より優先し、内蔵に無い樹種も足せます。3D では落葉・常緑で樹冠の色が、針葉樹は形が変わります。

## 見積書（Excel）

- 右の欄の「数量」→「見積書（Excel）を作る」。図の数量を工種ノートに当てて見積の行にし、見積書の Excel（INVOY の見積書の形）に流し込みます。宛名は現場名から（「春日邸」なら「春日　様邸」）、諸経費（%）とお値引き（円）も入れられます。窓の中で行と合計を確かめてから書き出します。
- 雛形は、同梱のもの（晃さんの見積書から宛名・連絡先を抜いたもの）か、「雛形を読み込む」で読ませた自分の見積書です。自分のものを読ませると社名・連絡先の欄もそのまま使います。表の行が足りなければ、最後の行を写して足します（印刷は一枚に縮まる設定のまま）。
- 諸経費は既定で 12%（工事の合計に掛ける）。見積金額（税込）は、合計（税抜）＋税額の千円未満を四捨五入し、差を「端数値引き」（切り上がるときは「端数調整」）として合計(税抜) の下の行に出します。
- Excel には式を入れます：内訳の金額＝数量×単価（四捨五入）、工事の見出し＝内訳の合計、諸経費＝工事の合計×12%、合計（税抜）＝見出しの合計、税額＝合計×10%（切り捨て）、端数値引き＝ROUND(合計＋税額, −3) −（合計＋税額）、見積金額（税込）＝合計＋税額＋端数値引き。Excel で単価を直しても合計が付いてきます。数量は「70平米」と見えますが中身は数です。
- 工種ノート（vault の `10_辞書/工種`）に工事の組み立てを書きます。「対象: 舗装／人工芝」なら、材料が人工芝の舗装の面積・周長から内訳（砕石転圧ｔ100㎜＝面積×0.1 立米 など）を作ります。初めの 4 件（人工芝施工工事・タイルテラス施工工事・防草シート砂利敷工事・砂利敷工事）は、渡してもらった見積の内訳と単価から作りました。単価は元の見積の単価の欄の値です（最初の現場は金額を帳尻合わせで変えていたため）。リポジトリの [vault/10_辞書/工種/](vault/10_辞書/工種/) にあります。
- 樹木は植木ノートの単価 × 本数で「植栽工事」にします。工種ノートの無い部材（土間コンクリート、ブロック塀 など）は、数量だけの行にして知らせます。

## 3D で見る（施主向けの絵）

- 上の「3D」で、図を立体にして見ます。建物は「高さ」（既定 6000 mm）、舗装は天端（無ければ地面 +30）、塀は高さ、縁石は 120 mm、樹木は樹高と葉張、植栽帯には低木を散らします。地面は計画 → 現況の高さ点で起伏を付け、舗装・建物の下はならします。太陽は図面の「北の向き」から南の空に置き、影を落とします。
- 視点は「鳥瞰」「人の目線」（敷地の南から目の高さ 1.5 m）「真上」。引いて回し、右ボタン（二本指）で動かし、ホイール（つまむ）で寄ります。
- 「絵を保存」で今の視点の絵を PNG（長辺 2400 画素ほど）にします。PC で vault のフォルダを選んであればそこへ、iPhone では共有シートへ。
- 3D は three.js（r180、MIT）を `app/vendor/three/` に同梱して使います。電波が無くても開けます。

## 地形（等高線・土量）

- 高さ点には「区分」があります。現況（GL、丸い印）と計画（FH、四角い印）で打ち分けます。舗装に「天端」を入れると、その舗装は天端の高さで平らな計画面として扱います。
- 現況・計画それぞれ三点以上あると、三角網（TIN）を作って等高線を描きます（現況は破線、計画は実線、5 本ごとに太く）。間隔は右の欄の「地形」で 20〜1000 mm から選びます。
- 土量は、敷地境界の中で「計画 − 現況」を格子で足し合わせて、切土・盛土・差引を出します。面（舗装・植栽帯など）を選ぶと、その中の土量も出ます。高さ点の範囲が敷地を覆っていなければ、その割合を知らせます。
- 等高線は図面の PDF・DXF（画層「等高線（現況）」「等高線（計画）」）・ノートの絵にも入り、土量はノートの「土量」の表に載ります。

## 緯度経度と地理院地図

- 右の欄の「場所」に地図アプリの緯度経度（`36.6513, 138.1810`、度分秒も可）を貼ると、そこを図の原点にします。座標系は緯度経度から目安を選びます（都道府県で決まるので確かめてください。長野県は第Ⅷ系）。
- 座標系が決まると、画面の中心の緯度経度が出て、「地理院地図を下図に敷く」で地理院タイル（標準地図・淡色地図・写真、100〜400 m 四方）を取って、測量座標の位置に敷きます（電波が要ります。出典：国土地理院）。地理院タイルは南北と東西で 1 画素の大きさが少し違うので、その分も合わせて置きます。
- 「座標をコピー」に緯度・経度の列も付きます。変換は国土地理院の計算式（GRS80・縮尺係数 0.9999）で、PROJ と 1mm 以内で合うことを試験で確かめています。

## Obsidian のノートに添える図の絵

- Obsidian へ書き出す（フォルダに揃える・ノートを書き出す）たびに、図面と同じ描き方の絵（SVG）をノートに添えます。Obsidian の中で図を見られます。

## 下図の画像の掃除

- 外した下図の画像は、元に戻せるように端末とフォルダに残ります。上の現場の欄の「使っていない下図の画像を掃除」で、どの現場の図からも使われていない画像を端末から消します（いま開いている図の元に戻す履歴に残っているものは消しません）。
- Obsidian のフォルダの分は、Obsidian の欄の「フォルダの使っていない下図の画像を掃除」で消します。フォルダの中のどの縄張りノートからも使われていない「下図_…」の画像だけが対象です。

## DXF を下図に敷く

- 道具の「下図」で DXF（建築士の図など）を選ぶと、線のまま下図に敷きます。拡大しても滲みません。単位（$INSUNITS）を読んで実寸で敷き、図に測量座標の原点があって DXF がその近く（1 km 以内）なら、測量座標の位置に重ねます。
- 作図のときは、DXF の線の端・頂点・円の中心に吸い付きます。なぞって部材にできます。
- 読むもの：線・ポリライン（ふくらみも）・円・弧・楕円・スプライン（おおまか）・塗りつぶしの外形・文字・ブロック（扉など）・寸法。非表示の画層は読みません。文字の DXF（R12〜2018）を読み、2007 より前は Shift_JIS、以後は UTF-8 とみなします。バイナリ DXF と DWG は読めません。
- 元の DXF は `下図_〈指紋〉.dxf` として端末に置き、Obsidian へもそのまま渡します。PDF の図面にも線のまま入ります。

## DXF

- 「図面」の欄の「DXF を書き出す」から。AutoCAD R12 形式・Shift_JIS・mm 単位で、Jw_cad・AutoCAD・Vectorworks で開ける形を狙っています。
- 部材の種類ごとに画層を分けます（敷地境界・建物・舗装・植栽帯・景石・塀・擁壁・縁石・見切・樹木・高さ・寸法・文字・注記）。円弧の辺はふくらみ（bulge）のまま渡します。
- 塗り（ハッチング）と下図は入りません。寸法は線と文字で描きます（寸法の部品ではありません）。

## 中身

- `app/` アプリ本体（静的ファイルのみ）
  - `src/model.js` 図のデータの形、合わせ（同期）、数量
  - `src/obsidian.js` ノートへの書き出しと読み込み
  - `src/vault.js` vault のフォルダへの直接書き込み、共有シート
  - `src/underlay.js` 下図（PDF・写真の読み込み、縮尺・二点での合わせ）
  - `src/sheet.js` `src/plot.js` `src/pdfwriter.js` 図面（用紙・縮尺・表題欄）と PDF の組み立て
  - `src/dxf.js` `src/sjis.js` DXF の書き出しと Shift_JIS への変換
  - `src/survey.js` 平面直角座標（座標一覧の読み取り・座標求積・図との行き来）
  - `src/geometry.js` `src/hit.js` `src/render.js` `src/main.js` 計算・当たり判定・描画・操作
- `app/vendor/pdfjs/` PDF を読むための pdf.js 4.10.38（Apache 2.0、電波なしで使うため同梱）
- `tests/` 試験（`node --test`）
- `docs/` 確認事項・機能台帳・受け渡しの説明
