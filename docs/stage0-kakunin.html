依頼の理解（三行）

  • 山波創苑専用の外構・造園CADを、Obsidian の非公開プラグイン（Windows と iPhone で同じもの）として段階的に作る。2Dの図が唯一の正本で、3D・数量・見積・出力はそこから生まれ、図面・写真・台帳は vault に置いて Obsidian Sync で運ぶ。
  • 部材カタログの物量では競わない。操作の軽さ、石・植栽・地形の細かさ、施主に見せる絵の質、寒冷高地と傾斜地の条件で勝つ。地域の数値は根拠を確かめてから既定値にする。
  • 各段は「提案→裁可→実装→受け入れ確認→山彦班点検」。次は仕様の確定→iPhone 実機での試作計測→第一段。本番の vault では試さず、作業が消えないことを最優先にする。

試験用 vault の支度（決定「一」の手順）

本番の YAMANAMI-BRAIN には一切触りません。Obsidian の画面の言葉は、日本語表示と英語表示の両方を書いています。見当たらない項目があれば、その画面の写真を送ってください。当て推量で先へ進まないでください。

一　Plus に上げる（PC のブラウザ）

  1. ブラウザで https://obsidian.md/account を開き、Obsidian のアカウントでログインする。
  2. Sync の欄で、プランを変える操作（英語表示では「Change plan」や「Upgrade」）を押し、Plus を選んで支払いを確かめる。
  3. 成功：Sync の欄が Plus、容量が 10 GB になっている。
  4. 失敗したら：ページを再読み込みする。変わらなければ支払い方法の欄と、届いた確認メールを見る。

二　PC に試験用 vault の置き場所を作る（PowerShell）

  1. スタートボタンを右クリック →「ターミナル」または「Windows PowerShell」を開く。
  2. 次の一行を打って Enter：
    New-Item -ItemType Directory -Path C:\nawabari-shiken
  3. 成功：Directory: C:\ の下に nawabari-shiken と表示される。OneDrive の外（C:\Users\…\OneDrive の下ではない）なので、二重同期に巻き込まれない。
  4. 失敗したら：「既に存在します」と出たら、そのまま次へ進んでよい。「アクセスが拒否されました」と出たら、その文面を送ってください。

三　PC で試験用 vault を作り、同期につなぐ（Obsidian）

  1. Obsidian の左下の保管庫名を押す →「保管庫を管理…」（Manage vaults…）。
  2. 「新しい保管庫を作成」（Create new vault）→ 名前に 縄張り台-試験、場所に C:\nawabari-shiken を選んで「作成」。新しい窓で試験用 vault が開く。
  3. 設定（左下の歯車）→「コアプラグイン」（Core plugins）→「同期」（Sync）をオン。
  4. 設定 →「同期」→ リモート保管庫の「選択」（Choose）→「新しい保管庫を作成」（Create new vault）。名前は 縄張り台-試験。暗号化のパスワードを決め、紙か領収書PWAとは別の安全な場所に書き留める（忘れると中身を戻せない）。「作成」→「接続」（Connect）。
  5. 同じ「同期」の画面で、次をオンにする：「その他のファイル形式」（Sync all other types）、「インストール済みのコミュニティプラグイン」（Installed community plugins）、「有効なコミュニティプラグインの一覧」（Active community plugin list）。競合の解決は「競合ファイルを作る」（Create conflict file）にする。
  6. 設定 →「コミュニティプラグイン」（Community plugins）→「制限モードをオフにする」（Turn on community plugins）。
  7. 成功：窓の右下の同期の印が、くるくる回った後に緑の✓になる。
  8. 失敗したら：印が赤や黄のままなら、印を押して出る文面をそのまま送ってください。

四　iPhone に同じ vault を開く（Obsidian）

  1. Obsidian を開き、左の引き出しを出して保管庫名を押す →「保管庫を管理」（Manage vaults）→「新しい保管庫を作成」（Create new vault）。
  2. 名前は 縄張り台-試験。「iCloud に保存」（Store in iCloud）はオフにして「作成」。
  3. 設定 →「コアプラグイン」→「同期」をオン →「同期」→ リモート保管庫の「選択」→ 一覧の 縄張り台-試験 →「接続」→ 三で決めたパスワードを入れる。
  4. 三の 5・6 と同じ項目を、iPhone 側でもオンにする（これらは端末ごとの設定）。

五　通るか確かめる

  1. PC の試験用 vault でノート「同期確認」を作り、「PC から」と書く。
  2. 成功：一分ほどで iPhone の試験用 vault に「同期確認」が出る。iPhone で「iPhone から」と書き足すと、PC にも出る。
  3. 失敗したら：両方の端末で、同期の設定画面のリモート保管庫の名前が 縄張り台-試験 になっているかを見る（YAMANAMI-BRAIN になっていたら、そこで止めて連絡してください）。
  4. 確かめ終えたら「同期確認」は消してよい。
