# 機能台帳

状態の語は次の意味で使っています（ずれていれば直します）。

- **種袋**：やることに載っているが、まだ手を付けていない
- **育苗床**：作っている途中
- **接ぎ木床**：作り終え、受け入れ確認・点検を待っている
- **花壇**：受け入れ済みで、使っている
- **休眠棚**：やらないと決めた、または止めている
